Deploy Branch Agent on Northflank with a one-click template and access it through the web Control UI. This is the easiest "no terminal on the server" path: Northflank runs the Gateway for you.

## How to get started

1. Click [Deploy Branch Agent](https://northflank.com/stacks/deploy-branch) to open the template.
2. Create an [account on Northflank](https://app.northflank.com/signup) if you don't already have one.
3. Click **Deploy Branch Agent now**.
4. Set these required environment variables:
   - `BRANCH_GATEWAY_TOKEN` (use a strong random value)
   - `BRANCH_STATE_DIR=/data/.branch`
   - `BRANCH_WORKSPACE_DIR=/data/workspace`
5. Click **Deploy stack** to build and run the Branch Agent template.
6. Wait for the deployment to complete, then click **View resources**.
7. Open the Branch Agent service.
8. Open the public Branch Agent URL at `/branch` and connect using the configured shared secret. This template uses `BRANCH_GATEWAY_TOKEN` by default; if you replace it with password auth, use that password instead.

From the Northflank shell, run the read-only deployment preflight:

```bash
branch doctor --json
```

## What you get

- Hosted Branch Agent Gateway + Control UI
- Persistent storage via a Northflank Volume (`/data`) so `branch.json`, shared and per-agent SQLite auth stores, channel/provider state, sessions, and workspace survive redeploys

## Connect a channel

Use the Control UI at `/branch`, or run `branch onboard` via SSH for channel setup instructions:
