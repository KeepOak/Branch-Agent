# Cloudflare Branch Agent plugin

Official Branch Agent plugin for Cloudflare R2 storage locations.

## Install

```sh
branch plugins install @branch/cloudflare
```

## Docs

See `docs/plugins/cloudflare.md` in the Branch Agent repository, or the published docs at <https://github.com/KeepOak/Branch-Agent/tree/main/engine/docs/plugins/cloudflare>, for bucket setup, credentials, and storage configuration.
