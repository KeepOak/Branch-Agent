# Bundled plugin icon sources

Every top-level bundled plugin ships one package-local opaque 512×512 `assets/icon.png`. Third-party marks remain their owners’ property and identify their integrations; attribution does not grant trademark rights. Runtime never fetches these URLs.

## Uniform white presentation

All bundled identities, including native Branch Agent plugins, use a pure-white tile. Center the meaningful standalone artwork in approximately 70–80% of the canvas while preserving its aspect ratio, geometry, and intentional internal details. Avoid embedding a smaller colored app square inside a white border. Use dark or colored marks rather than white-on-white. Shared native/fallback identities use the same static red mascot from `ui/public/favicon.svg`, without its animation or a dark tile. Activity SVGs remain unchanged.

The complete 159-plugin inventory was refreshed against main `208132c299208871dbda7fe855aa0bbd9107ce9b` before normalization. Prior mixed-brand-square / near-black presentation is superseded. Official standalone vectors are preferred; existing main artwork is retained when already suitable. Where the only supplied raster has a plate, the table identifies its foreground extraction rather than claiming an unchanged official white-tile asset. Foreground geometry and optical sizing were reviewed in the complete inventory, not inferred from background color alone.
