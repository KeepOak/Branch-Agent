# Branch Agent Synthetic Provider

Official Branch Agent provider plugin for Synthetic's hosted Anthropic-compatible
API.

Install from Branch Agent:

```bash
branch plugins install @branch/synthetic-provider
branch gateway restart
```

Configure `SYNTHETIC_API_KEY`, then select a `synthetic/<model-id>` model.

See https://github.com/KeepOak/Branch-Agent/tree/main/engine/docs/providers/synthetic for model and configuration
details.
