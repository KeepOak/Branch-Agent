# Vercel AI Gateway Branch Agent provider

Official Branch Agent provider plugin for Vercel AI Gateway.

## Install

```sh
branch plugins install @branch/vercel-ai-gateway-provider
```

## Docs

See `docs/providers/vercel-ai-gateway.md` in the Branch Agent repository, or the published docs at `https://github.com/KeepOak/Branch-Agent/tree/main/engine/docs/providers/vercel-ai-gateway`.
