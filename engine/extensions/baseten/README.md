# Branch Agent Baseten Provider

Official Branch Agent provider plugin for Baseten Model APIs, with DeepSeek V4.1 Flash as the starter model.

Install from Branch Agent:

```bash
branch plugins install @branch/baseten-provider
branch gateway restart
```

See <https://github.com/KeepOak/Branch-Agent/tree/main/engine/docs/providers/baseten> for setup and configuration.
