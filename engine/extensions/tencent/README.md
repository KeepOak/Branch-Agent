# Tencent Cloud Branch Agent provider

Official Branch Agent provider plugin for Tencent Cloud.

## Install

```sh
branch plugins install @branch/tencent-provider
```

## Docs

See `docs/providers/tencent.md` in the Branch Agent repository, or the published docs at `https://github.com/KeepOak/Branch-Agent/tree/main/engine/docs/providers/tencent`.
