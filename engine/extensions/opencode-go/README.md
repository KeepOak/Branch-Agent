# Branch Agent OpenCode Go Provider

Official Branch Agent provider plugin for the OpenCode Go model catalog.

OpenCode Go is bundled with Branch Agent for this release; no separate plugin
installation is required.

Configure `OPENCODE_API_KEY` or `OPENCODE_ZEN_API_KEY`, then select an
`opencode-go/...` model.

See <https://github.com/KeepOak/Branch-Agent/tree/main/engine/docs/providers/opencode-go> for setup and the current
model catalog.
