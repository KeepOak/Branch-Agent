# Slack huddles

Join an active Slack huddle through a dedicated Slack user signed into the Branch Agent Chrome profile. This plugin is disabled by default.

```bash
branch plugins install @branch/slack-huddles
branch plugins enable slack-huddles
```

See https://github.com/KeepOak/Branch-Agent/tree/main/engine/docs/plugins/slack-huddles for setup, modes, audio routing, captions, and limitations.

- Plugin id: `slack-huddles`
- Tool: `slack_huddles`
- CLI: `slackhuddles`
- Package: `@branch/slack-huddles`
- Minimum Branch Agent host: `2026.7.2`
