# OpenCode Zen Branch Agent provider

Official Branch Agent provider plugin for the OpenCode Zen model catalog, image
understanding, and native OpenCode session browsing.

## Install

```sh
branch plugins install @branch/opencode-provider
branch gateway restart
```

## Docs

See `docs/providers/opencode.md` in the Branch Agent repository, or the published
docs at `https://docs.openclaw.ai/providers/opencode`.
